MIDI Monitor

Monitor incoming notes, controls, channels, clock, and transport. Newest messages appear first.

Controls

  • Reset: clear message history
  • Freeze: hold the display; incoming messages are not saved

Columns

Column Meaning
Ch MIDI channel, 1–16; - for system messages
Msg Message type, including CC or program number
Val Value, note, velocity, pressure, or position
ST Status number: message type and channel, where applicable
D1 First data number, usually note or controller; - if unused
D2 Second data number, usually velocity or value; - if unused
Hex Message in hexadecimal, for comparison with device manuals

CC and program numbers use 0–127; some instruments label programs 1–128. Note 60 is C4 here; compare note numbers when octave names differ.

Message types

In hex codes such as 9n, n = 0–15 represents channels 1–16.

Message Status Display
Note off 8n Note name/number and release velocity
Note on 9n Note name/number and velocity; zero velocity shows Note off (v=0)
Polyphonic pressure An Note name/number and pressure
Control change Bn Controller number in Msg; value 0–127 in Val
Program change Cn Program number in Msg; Val blank
Channel pressure Dn Pressure value 0–127
Pitch bend En 0–16383 and signed −8192–8191; center 8192 / signed 0
MIDI time code quarter frame F1 Raw data; not assembled into timecode
Song position pointer F2 Song position in sixteenth notes
Song select F3 Raw song number
Tune request F6 Message name only
Timing clock F8 Clock
Start FA Message name only
Continue FB Message name only
Stop FC Message name only
Active sensing FE Message name only
System reset FF Reset; does not clear the monitor
Relative encoder Bn Raw CC values; direction and amount depend on the controller
High-resolution CC Bn CC pairs shown separately; no combined high-resolution value
RPN / NRPN Bn CC sequences shown separately; no combined parameter name or value

Notes

  • Devices and ports: Lyte receive_midi() supplies no source ID; the monitor cannot identify or select devices. Choose sources through Audulus, your host, or MIDI routing. Use separate channels or isolate one source. Clock and transport have no channel.
  • SysEx: Lyte receive_midi() does not deliver SysEx, so it does not appear in the monitor, including Hex. Use a SysEx-capable utility for preset dumps and other SysEx data.
  • Reserved statuses: F4, F5, F9, and FD are flagged as undefined if received.
