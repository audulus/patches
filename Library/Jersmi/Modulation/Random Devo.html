Random Devo

Description

Clocked modulation sequencer with 1–16 steps. Start with a pattern, then use devolve to introduce random changes as it repeats.

Controls

  • ptrn: selects a starting pattern. rdm gives random values; center, low, and high give constant levels; up and down give rising and falling patterns. Press regen to apply it.
  • type: selects how the sequence evolves:
    • random: occasionally replaces a step with a new random value.
    • mutate: shifts step values gradually, allowing the pattern to drift.
    • walk: adds a random upward or downward change to each step.
  • devolve: increases the chance of replacement in random, the depth of change in mutate, or the size of changes in walk. At minimum, random and mutate keep the sequence fixed; walk still makes small changes.
  • steps: sequence length, 1 to 16.
  • regen: restarts with the selected pattern. With rdm, creates fresh random values.

Ports

  • G input: connect a clock or gate sequence to advance the steps.
  • M outputs: stepped and smooth modulation, both ranging from 0 to 1. The smooth output glides between values using the interval between incoming gates.

Notes

  • Repeating pattern: select random or mutate, turn devolve to minimum, choose ptrn, and press regen.
  • Evolving pattern: raise devolve and try each type. Changes accumulate over successive passes. Press regen to start over; rdm makes a new random pattern each time.
  • Stepped or smooth: use the stepped M output for distinct changes and the smooth M output for gliding modulation.
