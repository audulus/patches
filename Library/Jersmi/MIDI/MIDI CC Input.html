MIDI CC Input

Turn eight MIDI controls into modulation signals for an Audulus patch. Connect the outputs to parameters such as filter cutoff, effect amount, or envelope settings.

Configure your controls

The channel, eight CC assignments, and display format are easy to change in the Lyte script’s init section. The display updates to match your assignments.

  1. Open the module, select its Lyte DSP node, and open the script editor.
  2. Find init { near the top. Edit these three settings, leaving the rest of the section intact:
midi_ch = 1
cc_numbers = [1, 2, 3, 4, 5, 6, 7, 8]
display_normalized = true
  • midi_ch: choose your controller’s MIDI channel, 1–16.
  • cc_numbers: enter eight CC numbers, each 0–127. Their order matches the eight outputs from top to bottom: the first entry feeds output 1 (val0), the last feeds output 8 (val7).
  • display_normalized: use true to display values from 0 to 1, or false for MIDI values 0–127. This changes the display only; outputs always remain 0–1.

For example, to receive channel 2 with CC 74 on the first output and CC 71 on the second:

midi_ch = 2
cc_numbers = [74, 71, 1, 11, 7, 10, 73, 72]

Apply the edit and save the patch. Move each hardware or software control and check its CC number and value on the display. Use MIDI Monitor to identify a control’s channel and CC number if needed.

Use as modulation

Connect an output to an Audulus modulation input—for example, filter cutoff, effect amount, or an envelope parameter. Each port follows its assigned CC. Scale or offset the signal in your patch when a destination needs a different range.

Values

Each output ranges from 0 to 1, corresponding to MIDI values 0–127, and holds its last received value. Outputs start at 0. The display shows the channel, controller numbers, and current values.

Notes

Use controls that send absolute CC values. Relative encoders require a different decoder. Only the configured channel and CC numbers are received; there is no front-panel MIDI learn.
